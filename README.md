# FOLDCUT — Fashion E-Commerce Website

> **Cut Different. Wear Different.**  
> Premium fashion e-commerce for Bangladesh — built with performance, authenticity, and brand integrity.

🌐 **Live:** [foldcut.online](https://foldcut.online)

---

## Pages

| Page | URL | Description |
|------|-----|-------------|
| Homepage | `/` | 10-section landing — hero, categories, new arrivals, editorial, best sellers, limited drop, brand story, trust bar, social grid, newsletter |
| Shop | `/shop` | Full catalog with filter sidebar, sort, quick-add |
| Product Detail | `/product` | Gallery, variants, size guide, reviews, related products |
| Checkout | `/checkout` | Bangladesh-optimized — COD, bKash, Nagad, card |

## Tech Stack

- **Frontend:** Vanilla HTML + CSS (design tokens) + JS (ES6+)
- **Backend (production):** WordPress + WooCommerce
- **Payments:** COD native · bKash · Nagad · SSLCommerz
- **Hosting:** Vercel (static preview) → WooCommerce (production)
- **Market:** Bangladesh 🇧🇩 · Currency: ৳ BDT
